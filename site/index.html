이 로그에서 어디부터 봐야 할까?

대용량 MCAP 파일을 로컬에서 읽고, 메시지 타이밍이 가장 불규칙한 시간 구간(gap, jitter, 메시지 수 부족, 순서가 뒤바뀐 timestamp)을 순서대로 정리합니다. Foxglove나 기존 도구에서 바로 그 구간을 여세요.

VeluneOS Compare · Reference vs Target

두 실행 사이에 무엇이 달라졌을까?

Velune Adapter가 두 실행을 내 컴퓨터에서 하나의 파생 파일로 준비합니다. VeluneOS Compare는 한 실행에만 있는 stream, 메시지 간격 변화, 활동 손실과 회복, timestamp 표현 변화를 각각의 구간과 evidence 품질과 함께 보고합니다.

작동 방식

지금의 워크플로우 그대로, 앞단에 구조 비교 한 단계.

새로운 기록 방식은 필요 없습니다. 팀이 이미 만들고 있는 MCAP 파일을 읽습니다.

  1. 기록 선택 고객 환경

    조사할 MCAP 로그 하나, 또는 Reference 실행과 Target 실행(예: 변경 전과 후). Reference는 사용자가 정한 기준일 뿐, 그것이 정상이라는 뜻은 아닙니다.

  2. 로컬 실행 내 컴퓨터

    Trace는 전부 내 컴퓨터에서 실행됩니다. Compare의 경우 Velune Adapter가 두 실행을 로컬에서 읽어 comparison.velune 파일 하나와, 그 안에 무엇이 들어 있는지 보여주는 preview를 만듭니다.

  3. 파생 파일 비교 VeluneOS Compare

    VeluneOS Compare에는 준비된 파일만 업로드됩니다. 원본 MCAP, 메시지 payload, 원래 topic 이름, 절대 timestamp는 포함되지 않으며, 리포트를 돌려준 뒤에는 아무것도 저장되지 않습니다.

  4. 관측 결과 확인

    하나의 결정, 그리고 검토 순서대로 정리된 차이. 각각에 시간 구간, 양쪽 값, evidence가 얼마나 뒷받침하는지가 표시됩니다.

  5. 검증하고 결정 엔지니어

    해당 구간을 기존 도구에서 열고, 시스템에 대해 알고 있는 것과 대조한 뒤 엔지니어링 결정을 내리세요. VeluneOS는 그 직전에서 멈춥니다.

AI는 엔지니어링에

구조 비교에는 언어 모델이 필요하지 않습니다.

두 실행 사이에서 어떤 stream이 달라졌는지 찾는 일은 반복 가능하고 규칙으로 정의되는 작업입니다. VeluneOS는 고정된 규칙으로 이 일을 처리하므로, 팀의 AI 사용량과 집중력은 추론, 코딩, 설계처럼 정말 필요한 질문에 쓸 수 있습니다.

수동 리플레이 원본 로그에 범용 AI 사용 VeluneOS 구조 비교
방식 두 실행을 재생하고, timestamp를 맞추고, topic을 하나씩 확인 질문할 때마다 로그 데이터를 모델에 전달 파생 구조에 대해 고정·문서화된 비교 규칙 적용
재현성 누가, 얼마나 오래 보느냐에 따라 다름 실행과 프롬프트에 따라 답이 달라질 수 있음 같은 입력, 같은 결과
모델 사용 없음 매번 추론 필요 비교 과정에 LLM 추론 없음
원본 데이터 그대로 유지 도구와 데이터 약관에 따라 다름 원본 MCAP은 로컬에, 비교는 파생 구조로만
최종 판단 엔지니어 답을 검증한 뒤 엔지니어 보고된 구간에서 시작해 엔지니어

이 주장의 범위. 비교가 LLM 추론 없이 결정론적으로 실행된다는 것까지가 저희의 주장입니다. 실제 고객 워크플로우에서의 시간·토큰 절감은 아직 측정하지 않았으며, VeluneOS가 AI 기반 조사를 대체하지는 않습니다. 그 안의 반복 단계 하나를 덜어줄 뿐입니다.

판정이 아닌 evidence

VeluneOS가 보고하는 것

  • 한 실행에는 있고 다른 실행에는 없는 stream
  • 메시지 간격 변화, 활동 손실과 회복
  • 타이밍과 구분해 보고하는 timestamp 표현 변화
  • 모든 결과의 evidence 품질과 coverage 한계
  • 재현 가능한 HTML, Markdown, JSON 출력

VeluneOS가 판단하지 않는 것

  • 근본 원인
  • 결함, 책임, 법적 책임
  • 로봇의 안전 여부
  • 변경이 회귀(regression)인지 여부
  • 릴리스 GO / NO-GO

리뷰할 변경이 있으신가요?

두 실행 사이에 무엇을 바꿨는지, 무엇을 알고 싶은지 알려주세요. Private Beta 기간에는 각 팀과 실제 비교를 직접 함께 진행합니다.

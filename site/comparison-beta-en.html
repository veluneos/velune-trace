How It Works

Prepare locally. Compare in VeluneOS.

Raw MCAP stays on your machine during preparation. Only one derived file — comparison.velune — is uploaded.

STEP 01

Reference Run + Target Run

Pick the run you're comparing from (Reference) and the run you're comparing against it (Target).

STEP 02

Prepare locally

Velune Local Prepare turns both runs into one comparison.velune file, on your machine. Raw MCAP never leaves it.

STEP 03

Upload comparison.velune

Upload the single prepared file to VeluneOS Compare.

STEP 04

Inspect structural differences

See what changed between Reference and Target, and where to look first.

Data Boundary

See what may be transferred and what stays local.

COMPARISON BUNDLE

Derived structures that may be transferred after approval

  • Canonical Topic Role
  • Relative-time events and Evidence Windows
  • Gap, jitter, and count profiles
  • Structural features required for Reference–Target comparison
  • Context explicitly approved by the customer
STAYS LOCAL

Raw data not accepted by standard Cloud Comparison

  • Raw MCAP and rosbag2
  • Raw images, video, and audio
  • Raw point clouds and actual GPS
  • Actual topic and node names and absolute timestamps
  • Direct company, site, and robot identifiers

Exporter output is not automatically described as fully anonymous. During the initial Beta, Bundle structure and transfer boundaries are reviewed together with the customer.

Beta Operation

We validate the operating model first, then automate it.

Initial Private Beta

The Comparison Engine generates the report while a VeluneOS operator reviews input errors and execution status in a service-led operating model.

  • Pre-check Bundle schema and support eligibility
  • Handle Comparison Job failures
  • Review the quality of engine-generated reports
  • Collect engineer feedback
Automated operating model

The service evolves so customers upload Bundles directly and the server automates validation, comparison, reporting, feedback, and deletion.

  • Automated Reference–Target comparison
  • Report URL, JSON, and Markdown delivery
  • Organization access and retention controls
  • Operators handle exception jobs only

How it works

The workflow you already have, with a structural pass in front.

No new recording setup. VeluneOS reads the MCAP files your team already produces.

  1. Pick the recordings your environment

    One MCAP log for an investigation, or a Reference run and a Target run — for example before and after a change. Reference is the baseline you choose, not a claim that it is correct.

  2. Run locally your machine

    Trace runs entirely on your machine. For Compare, Velune Adapter reads both runs locally and writes one comparison.velune file plus a preview listing exactly what it contains.

  3. Compare the derived file VeluneOS Compare

    Only the prepared file is uploaded to VeluneOS Compare. Raw MCAP, message payloads, original topic names and absolute timestamps are not included, and nothing is stored after the report is returned.

  4. Read the observations

    One decision, then the differences in review order — each with its time window, the values from both runs, and how well the evidence supports it.

  5. Verify and decide your engineers

    Open the windows in your own tools, check them against what you know about the system, and make the engineering decision. VeluneOS stops before that step.

Save AI for engineering

The structural pass does not need a language model.

Finding which streams changed between two runs is a repeatable, rule-based task. VeluneOS does it with fixed rules, so your team's AI budget and attention go to the reasoning, coding and design questions that need them.

Scope of this claim. We state that the comparison runs without LLM inference and is deterministic. We have not yet measured time or token savings in customer workflows, and VeluneOS does not replace AI-assisted investigation. It removes one repeatable step from it.

Evidence, not verdicts

Find the events. Engineers find the cause.

VeluneOS reports

  • Streams present in one run and absent in the other
  • Message-interval changes and activity loss, with recovery
  • Timestamp representation changes, kept apart from timing
  • Evidence quality and coverage limits for every finding
  • Reproducible HTML, Markdown and JSON output

VeluneOS never decides

  • Root cause
  • Fault, responsibility or liability
  • Whether the robot is safe
  • Whether a change is a regression
  • Release go / no-go

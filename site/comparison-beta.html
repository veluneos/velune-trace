Use it

Prepare locally. Upload one file.

  1. Install the Adapter Kit on the machine with your recordings (Python 3.12 or 3.13).
  2. velune mapping init on the Reference and Target MCAP; label streams and confirm any pairing the Adapter asks about.
  3. velune prepare writes comparison.velune and a preview of everything inside it.
  4. Sign in to Compare, upload comparison.velune, download the report.

Raw MCAP is not uploaded; Compare accepts only comparison.velune. Velune Trace is not required. Step-by-step guide

What the report contains

  • DecisionREVIEW_REQUIRED, NO_MATERIAL_STRUCTURAL_CHANGE, INCONCLUSIVE_DIFFERENCE or INSUFFICIENT_COVERAGE
  • FindingsStreams in one run only, interval changes, activity loss and recovery, timestamp representation changes
  • For each findingIts window, values from both runs and evidence quality
  • OutputHTML, Markdown and JSON, downloaded in the browser

A review order, not a severity score. Compare does not decide root cause, fault, safety, regression or release readiness. Reading the report

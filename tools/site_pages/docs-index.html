Getting started

VeluneOS has two tools. Pick the one that matches your question — they work independently.

One log → Velune Trace“Where in this log should I look first?” Open source, runs locally, no account. Two runs → VeluneOS Compare“What changed between these two runs?” Prepare locally with the Adapter Kit, compare in the hosted Private Beta.

The Compare workflow

  1. Get access. Compare is a Private Beta. Request access; we confirm data-use terms in writing and send Compare credentials.
  2. Install the Adapter Kit on the machine that holds your recordings. Install
  3. Prepare two runs locally: discover streams, name the ones you care about, confirm any uncertain pairing, and generate comparison.velune. Prepare two runs
  4. Review the preview (comparison.preview.json) to see exactly what the file contains. Review the preview
  5. Sign in and upload at compare.veluneos.ai/compare. Upload and read the report
  6. Read the report and verify the reported windows in your own tools. The engineering decision is yours.
Raw MCAP stays on your machine. The Adapter never uploads anything; you upload one derived file yourself. See Data boundaries.
